# CatNewTab
A cute new tab page filled with... cats!

# How it works
Well, I guess you just type in a search query and it searches it on duckduckgo! Besides, you can find random cat facts using the free Ninja API and see more cats in the background. You can see the time in the top-left and the background is... a cat.

No AI was used in the code, except for github copilot for autocompletion.

# How to set up

You can clone the repo, and either open the index.html file locally or host it on a server. It has NO frameworks, so it works out of the box! It's just pure handwritten html/css/js. You do not need an API key for the Ninja API.
